# RFCs — Request for Comments

Registro das decisões técnicas relevantes do projeto OS Management, discutidas e
avaliadas antes da implementação. Diferente dos [ADRs](../adr/README.md) — que
registram uma decisão arquitetural já tomada e suas consequências — o RFC
documenta o **processo de avaliação de alternativas** para uma questão técnica
com impacto em múltiplos repositórios ou componentes.

## Convenção

Cada RFC segue a estrutura:

1. **Contexto** — o problema e as restrições do projeto.
2. **Alternativas Consideradas** — opções avaliadas, com prós e contras.
3. **Decisão** — a alternativa escolhida e por quê.
4. **Consequências** — impactos técnicos, operacionais e de custo.
